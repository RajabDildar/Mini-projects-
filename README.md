# Mini Projects

This repository contains 5 projects in HTML, CSS, and JavaScript. Each project is a small, interactive frontend app designed to practice core web development concepts such as DOM manipulation, event handling, styling, and responsive UI design.

## Overview

The collection includes a mix of utility and game-based applications:

- Calculator for quick arithmetic operations
- Quiz App for interactive question-based learning
- ToDo App for managing daily tasks
- Stone Paper Scissors for a simple browser game experience
- Currency Converter for converting values between currencies

## Included Projects

### 1. Calculator
A basic calculator app with arithmetic functionality and a clean user interface.

### 2. Quiz App
A small quiz application that asks questions and tracks the score as the user answers.

### 3. ToDo App
A task management app for adding, marking complete, and removing items from a to-do list.

### 4. Stone Paper Scissors
A classic hand-game simulation where the user plays against the computer.

### 5. Currency Converter
A lightweight currency conversion tool for converting values between available currencies.

## Tech Stack

- HTML
- CSS
- JavaScript

## How to Run

Each project is a standalone frontend app. To use any of them:

1. Open the project folder.
2. Open the `index.html` file in a browser, or
3. Run a local development server if preferred.

## Purpose

This repository is ideal for learning and practicing frontend development with small, practical projects. It is beginner-friendly and demonstrates how HTML, CSS, and JavaScript can be combined to build useful web applications.
